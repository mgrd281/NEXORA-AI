# اختبار تطبيق iPhone مع نشرك على Railway

النسخة الإنجليزية: [ios-testing.md](ios-testing.md). انشر الخادم أولًا:
[deploy-railway.ar.md](deploy-railway.ar.md) (تحتاج منه إلى **نطاق الواجهة البرمجية**، القسم 7، وإلى
**حساب المالك**، القسم 10). خلفية عن التطبيق: [apps/ios/README.md](../../apps/ios/README.md)
و[apps/ios/ARCHITECTURE.md](../../apps/ios/ARCHITECTURE.md) (بالإنجليزية).

> **لم يُبنَ تطبيق iPhone قط (لم تمرّ شيفرته على المترجم البرمجي أبدًا).** كُتب في بيئة لا تحتوي Xcode
> ولا أدوات Swift. جرى فحصه بنيويًا
> (ملفات JSON التجريبية مقابل عقود الواجهة البرمجية، وتغطية القيم والنصوص، وفهارس النصوص، وتحليل نحوي
> لشيفرة Swift)، لكنه **لم يُفحص فحص أنواع ولم يُبنَ ولم يُشغَّل**. توقّع أن يُظهر البناء الأول أخطاء
> ترجمة (compiler errors). هذا طبيعي في هذه المرحلة: انسخها كما يشرح [القسم 5](#5-إذا-فشل-البناء-أرسل-الأخطاء)
> وأرسلها، وستُصلَح. لا شيء مما تفعله هنا يمكن أن يضرّ بالخادم أو ببياناتك.

## 1. ما تحتاج إليه

| العنصر                               | ملاحظات                                                                                                                                           |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| جهاز Mac عليه **Xcode 16 أو أحدث**   | يستخدم المشروع وضع لغة Swift 6 وحزمة iOS 18 SDK. افتح Xcode مرة واحدة ليثبّت مكوّناته                                                             |
| **Homebrew** و**XcodeGen** 2.42+     | `brew install xcodegen` — يُولَّد مشروع Xcode من `apps/ios/project.yml` ولا يُحفظ في المستودع                                                     |
| **Apple ID**                         | يكفي Apple ID مجاني لتشغيل التطبيق على هاتف iPhone **الخاص بك**. أما TestFlight أو إعطاء التطبيق لآخرين فيتطلب **برنامج Apple Developer** المدفوع |
| هاتف **iPhone بنظام iOS 18** أو أحدث | مع كابل USB للتشغيل الأول                                                                                                                         |
| **نطاق الواجهة البرمجية**            | مثل `https://api-production-xxxx.up.railway.app` — تأكد أنه يجيب: `curl -s https://<api domain>/readyz` ← `{"ok":true,"database":true}`           |

## 2. توجيه التطبيق إلى واجهتك البرمجية وتوليد المشروع

```bash
cd NEXORA-AI && git pull            # the clone from the deployment guide
cd apps/ios
cat > Config/Local.xcconfig <<'EOF'
// Per-developer settings, git-ignored. "//" starts a comment in xcconfig files,
// hence $() between the two slashes of https://.
JARVIS_API_BASE_URL = https:/$()/api-production-xxxx.up.railway.app
EOF
xcodegen generate                    # writes Jarvis.xcodeproj
open Jarvis.xcodeproj
```

- استبدل المضيف بـ **نطاق واجهتك البرمجية** — نطاق خدمة `api`، **وليس** نطاق الويب، بلا مسار وبلا شرطة
  مائلة في آخره.
- يُضمَّن `Config/Local.xcconfig` في إعدادَي Debug وRelease، ويتجاهله git. لا يقبل التطبيق إلا عناوين
  `https` (ويقبل `http` العادي لـ `localhost` فقط)؛ ومع غير ذلك يعرض شاشة إعداد بدلًا من شاشة تسجيل
  الدخول.
- لماذا `$()` بين الشرطتين؟ لأن `//` تبدأ تعليقًا في ملفات xcconfig.
- أعد تشغيل `xcodegen generate` بعد كل `git pull` يغيّر `apps/ios` (فهو يستبدل التعديلات التي أُجريت في
  إعدادات المشروع داخل Xcode).
- اللغات: إن لم تظهر الألمانية والعربية بعد التوليد في Xcode ← المشروع **Jarvis** ← **Info** ←
  **Localizations**، فأضفهما هناك مرة واحدة (فهارس النصوص تحتوي كل الترجمات أصلًا).

## 3. التوقيع (مرة واحدة)

1. Xcode ← **Settings** ← **Accounts** ← **+** ← Apple ID ← سجّل الدخول.
2. اختر المشروع **Jarvis** في المتصفح الجانبي ← الهدف **Jarvis** ← **Signing & Capabilities** ←
   **Team**: اسمك _(Personal Team)_. أبقِ _Automatically manage signing_ مفعّلًا. وافعل الشيء نفسه للهدف
   **JarvisTests** إن أردت تشغيل الاختبارات.
3. إن أبلغ Xcode أن معرّف الحزمة `ai.jarvis.app` غير متاح، فغيّر **Bundle Identifier** إلى قيمة فريدة مثل
   `com.yourname.jarvis`. وللاحتفاظ به بعد `xcodegen generate` التالي، غيّر `PRODUCT_BUNDLE_IDENTIFIER`
   في `apps/ios/project.yml` بالطريقة نفسها.

مع فريق شخصي مجاني (وفق قواعد Apple التي قد تتغير): يتوقف التطبيق عن الفتح بعد **7 أيام** (شغّله من
Xcode مجددًا لإعادة تثبيته)، ولا تتوفر قدرات مثل **Associated Domains** (لا تلزم إلا لربط Google/Microsoft
من الهاتف، القسم 7).

## 4. التشغيل في المحاكي (Simulator) أولًا

1. في شريط الأدوات اختر المخطط (scheme) **Jarvis** ومحاكي iPhone بنظام iOS 18 أو أحدث.
2. **Product ← Run** (⌘R). يستغرق البناء الأول بضع دقائق.
3. إن نجح البناء: يفتح التطبيق على شاشة تسجيل الدخول. سجّل الدخول ببريد المالك وكلمة مروره من دليل
   النشر. جرّب الرئيسية، واطلب شيئًا، وافتح مهمة، ووافق أو ارفض، والإعدادات.

إن فشل البناء فتابع إلى القسم 5.

## 5. إذا فشل البناء: أرسل الأخطاء

**في Xcode:** افتح **Issue navigator** (⌘5)، وانقر داخل القائمة، وحدّد كل شيء (⌘A)، وانسخ (⌘C)، ثم
الصقه في ملف نصي. المهم هو **الأخطاء** الحمراء فقط؛ التحذيرات يمكن أن تنتظر.

**أو في Terminal** (يكتب كل خطأ مختلف في ملف على سطح المكتب):

```bash
cd NEXORA-AI/apps/ios
xcrun simctl list devices available | grep -i iphone      # pick an installed simulator name
xcodebuild -project Jarvis.xcodeproj -scheme Jarvis \
  -destination 'platform=iOS Simulator,name=iPhone 16' build 2>&1 \
  | grep -E "error:" | sort -u > ~/Desktop/jarvis-ios-errors.txt
wc -l ~/Desktop/jarvis-ios-errors.txt
```

استبدل `iPhone 16` باسم من مخرجات الأمر الأول إن لم يكن مثبتًا. وأرسل:

1. الملف `jarvis-ios-errors.txt` (أو القائمة المنسوخة)،
2. مخرجات `xcodebuild -version` و`sw_vers -productVersion`،
3. الخطوة التي فشلت (التوليد، البناء، التشغيل، تسجيل الدخول)، ولقطة شاشة إن تعطّل التطبيق.

تحتوي الأخطاء على أسماء ملفات وأرقام أسطر من هذا المستودع فقط — لا أسرار. كثيرًا ما تكشف جولة الإصلاح
الأولى أخطاء تالية (يتوقف المترجم عند بعض أنواع الأخطاء)، فتوقّع جولتين أو ثلاثًا.

**أين يُرجَّح ظهور الأخطاء** (وفق ARCHITECTURE.md وملاحظات من كتبوا تطبيق iOS):

- **التزامن الصارم في Swift 6** (`SWIFT_STRICT_CONCURRENCY: complete`): رسائل عن `@MainActor`
  و`Sendable` و`nonisolated`، أو «sending … risks causing data races»، أو «main actor-isolated … from a
  nonisolated context». الأنواع الموسومة `@unchecked Sendable` (‏`SpeechSession`
  و`ConversationAudioEngine` وصناديق نقر الصوت ومفوّض تركيب الكلام) هي الأكثر حساسية.
- **تسجيل الدخول إلى Google/Microsoft** (`Features/Connections/OAuthFlow.swift`): توقيع SwiftUI
  `WebAuthenticationSession.authenticate(using:callback:preferredBrowserSession:additionalHeaderFields:)`
  (حزمة iOS 17.4 SDK) وأنواع رد النداء في `ASWebAuthenticationSession` كُتبت من التوثيق دون مترجم.
- **الترجمة والتوطين**: فهارس `.xcstrings` (‏`Localizable` و`InfoPlist` و`AppShortcuts`) وقائمة اللغات
  (انظر القسم 2)؛ وعبارات App Shortcuts (‏`Intents/AskJarvisIntent.swift`، إطار AppIntents).
- **الكلام والصوت** (Speech وAVFoundation) لوضع الصوت — تُترجَم في المحاكي لكنها لا تعمل فعليًا إلا على
  جهاز حقيقي.
- أُبقيت أدوات بناء الواجهات في SwiftUI عند عشرة عناصر فرعية على الأكثر، لذا فأخطاء «extra argument»
  هناك ستكون مفاجئة — أبلغ عنها على أي حال.

## 6. التشغيل على هاتفك iPhone

1. صِل الهاتف بالكابل، وافتح قفله، واضغط **Trust** (الوثوق) على سؤال «Trust This Computer?».
2. اختر الهاتف وجهةً للتشغيل في Xcode. في المرة الأولى يطلب iOS تفعيل **وضع المطوّر (Developer Mode)**:
   في الهاتف **الإعدادات ← الخصوصية والأمن ← وضع المطوّر ← تشغيل**، ثم أعد التشغيل وأكّد.
3. **Product ← Run** (⌘R).
4. إن قال iOS إن المطوّر غير موثوق: **الإعدادات ← عام ← الشبكة الافتراضية الخاصة وإدارة الجهاز** ← Apple
   ID الخاص بك ← **وثوق**. ثم شغّل مجددًا.
5. سجّل الدخول بحساب المالك. أشياء لتجربتها: الطلب كتابةً؛ زر الصوت (اسمح بالميكروفون والتعرّف على الكلام
   عند الطلب)؛ التقدّم الحي لمهمة؛ طلب موافقة؛ الإعدادات ← الجلسات (يظهر iPhone جلسةً مستقلة — يمكنك
   إلغاؤها من الويب).

بعد التشغيل الأول لا يلزم الكابل في كل مرة إن ظهر الهاتف في Xcode للتشغيل عبر الشبكة
(_Window ← Devices and Simulators ← Connect via network_).

## 7. ما يعمل، وما يحتاج إلى إعداد إضافي

| الميزة                                                                            | حالتها في هذا الاختبار                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| --------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| تسجيل الدخول، الرئيسية، المهام، الموافقات، الذاكرة، المحادثات، الجداول، الإعدادات | يُفترض أن تعمل مع الواجهة البرمجية المنشورة بمجرد نجاح البناء                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| الصوت                                                                             | على الجهاز (التعرّف على الكلام وتركيبه من Apple)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| المرفقات                                                                          | فقط إن كان على الخادم تخزين ملفات (دليل النشر، القسم 13.2)؛ وإلا يذكر التطبيق أن الرفع غير متاح                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| الوصول إلى الويب، بريد SMTP                                                       | يُعدّان **على الويب**؛ ثم يعملان من التطبيق أيضًا                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Google / Microsoft                                                                | اربطهما **على الويب**؛ فيعمل الاتصال بعدها في التطبيق. أما الربط **من iPhone** فمعطّل افتراضيًا و**يُتجاوز في الاختبار الأول**: يتطلب `JARVIS_OAUTH_REDIRECT_URI` و`JARVIS_OAUTH_CALLBACK_HOST` و`JARVIS_ENTITLEMENTS` في `Local.xcconfig`، وعنوان إعادة التوجيه نفسه بـ https مسجّلًا لدى المزوّد وفي `OAUTH_REDIRECT_URIS`، وقدرة **Associated Domains** (برنامج Apple Developer المدفوع)، وملف `apple-app-site-association` يُقدَّم من نطاق الويب — وتطبيق الويب **لا** يقدّمه بعد ([apps/ios/README.md](../../apps/ios/README.md#connecting-google-and-microsoft-from-the-iphone-oauth)) |
| المكالمات الهاتفية                                                                | فقط إن كان Twilio مُعدًّا على الخادم                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

## 8. لاحقًا: TestFlight

يتطلب برنامج Apple Developer: أنشئ التطبيق في App Store Connect بمعرّف الحزمة الخاص بك، وأبقِ
`JARVIS_API_BASE_URL` في `Local.xcconfig` (لا قيمة افتراضية لبنى Release وهي ترفض البدء بدون عنوان https)،
ثم **Product ← Archive**، ثم **Distribute App ← TestFlight**. لا حاجة إليه لاختبار التطبيق على هاتفك.

| العَرَض                                               | الحل                                                                                                                                                                          |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `xcodegen: command not found`                         | `brew install xcodegen`                                                                                                                                                       |

| «Failed to register bundle identifier»                | القسم 3، الخطوة 3                                                                                                                                                             |
| «Untrusted Developer» / لا يفتح التطبيق على iPhone    | القسم 6، الخطوة 4؛ وبعد 7 أيام مع حساب مجاني شغّله من Xcode مجددًا                                                                                                            |
| لا يظهر وضع المطوّر                                   | صِل الهاتف بـ Xcode مرة واختره وجهةً للتشغيل، ثم ابحث مجددًا                                                                                                                  |
